# Sunnydale School

A responsive informational school webpage created for Performance Task #1.

## Technologies
- HTML5
- CSS3
- JavaScript

## Features
- Semantic page sections
- Responsive navigation menu
- Mission statement
- Upcoming events
- Contact information and client-side form interaction
- Mobile responsive layout
- CSS Grid and media queries

## Project Structure
- `index.html` — webpage structure
- `style.css` — visual design and responsive layout
- `script.js` — navigation and contact-form interaction

This is an educational project and does not connect to a backend database.
